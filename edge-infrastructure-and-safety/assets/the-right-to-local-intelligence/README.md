# Fieldlight Intelligence Infrastructure

Canonical visual assets for [The Right to Local Intelligence](../../the-right-to-local-intelligence.md).

The map shows the Fieldlight infrastructure topology:

1. Human / Local Authority
2. Household Node and Mobile Node
3. Neighborhood Intelligence Utility
4. Regional Anchor
5. Trusted Bridge
6. External Cloud

Authority, identity, memory, and consent remain local. Scoped delegation can move outward for capability, while results and an audit trace return to the local record.

## Files

- `fieldlight-intelligence-infrastructure.svg` — canonical 16:9 vector composition for reading surfaces, repositories, and board decks
- `fieldlight-intelligence-infrastructure-mobile.svg` — vertical vector composition for narrow reading surfaces
- `fieldlight-intelligence-infrastructure-1600x900.png` — presentation and sharing export
