# Assets

## Social Preview

- `social-preview.jpg` is the lightweight GitHub social preview image for this repository.
- `social-preview.png` is the higher-resolution source version.

GitHub does not automatically use a repository image file as the share card. To refresh or set the card, upload `assets/social-preview.jpg` from the repository settings:

```text
Settings -> General -> Social preview -> Edit -> Upload an image
```

Use the JPEG for upload because it is under 1 MB. The PNG is kept as the source asset.
