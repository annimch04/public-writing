# Templates

These templates implement the Fieldlight Archive Method 1.0.

Use the Markdown forms as one record per file. Use the CSV forms as append-only ledgers. Replace `ARC` with the archive's stable code.

## Sequence

1. [Accession](./accession.md)
2. [Source Register](./source-register.csv)
3. [Representation Register](./representation-register.csv)
4. [Orientation Map](./orientation-map.md)
5. [Evidence Packet](./evidence-packet.md)
6. [Connection Ledger](./connection-ledger.csv)
7. [Correction Log](./correction-log.csv)
8. [Analysis Memo](./analysis-memo.md)
9. [Publication Review](./publication-review.md)
10. [Prospective Transition Ledger](./prospective-transition-ledger.csv)

CSV files include headers plus one clearly labeled example row. Delete the example row before use.
