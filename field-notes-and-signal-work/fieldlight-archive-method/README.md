# Fieldlight Archive Method — Version 1.0 Package

This directory contains the operational materials supporting [The Fieldlight Archive Method](../fieldlight-archive-method.md).

## Package contents

- [Operational Protocol](./protocol.md) — folder model, registers, identifiers, status vocabulary, evidence rules, human–AI roles, and release checks.
- [Implementation Notes](./implementation-notes.md) — the concrete Version 1.0 toolchain, human–AI division of work, review modes, formats, and known technical limits.
- [Worked Example](./worked-example.md) — a content-redacted account of one real notebook workflow, including the scope correction that prevented a dense notebook from standing in for its batch.
- [Public Workbook](./fieldlight-archive-method-public-workbook.xlsx) — a derived, inspectable spreadsheet containing the schema, reusable ledgers, aggregate field-test evidence, the 71-record public-work register, correction examples, research agenda, and release gate.
- [Templates](./templates/) — blank records for accession, source inventory, orientation, evidence packets, connection claims, correction, analysis, publication review, and prospective research transitions.
- [Workbook Release Review](./public-workbook-release-review.md) — the public/private decision trail for publishing the derivative rather than the private master.
- [Version History](./version-history.md) — public release history and compatibility notes.

## Status

Version 1.0 is the first stable external specification. It is prepared from a private implementation that evolved through repeated application across physical, photographic, born-digital, academic, public-web, audio, social, and repository sources.

The package does not contain the private archive. Paths, names, source text, family information, credentials, precise locations, and sensitive findings have been excluded or abstracted. The workbook's public-work register contains public metadata and stable public IDs only; linked works retain their own rights status.
