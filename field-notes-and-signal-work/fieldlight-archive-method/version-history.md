# Version History

## 1.0 — August 2026

First stable external specification.

Introduces:

- the source-versus-representation model;
- the ten-stage path from scope through intentional publication;
- declared orientation coverage;
- stable, never-recycled identifiers;
- claim-level evidence basis and confidence;
- bounded evidence packets;
- human–AI responsibility boundaries;
- correction as a first-class archival record;
- separate private-analysis and public-release authority;
- templates and a redacted worked example.

The private working method used to develop this release carried internal revisions as new domains exposed missing rules. Those internal numbers are implementation history, not earlier public releases. Public Version 1.0 is the first version intended for external use.

## Compatibility rule

Minor versions may add fields, examples, or optional checks without changing the meaning of existing records. A major version is required if identifier semantics, evidentiary categories, privacy authority, or the source-versus-representation model changes incompatibly.
